Política de Privacidade — MonitorCanais

Última atualização: 3 de novembro de 2026.

O que é

O MonitorCanais é uma ferramenta pessoal, usada apenas pelo dono dos canais, para acompanhar o desempenho dos seus próprios vídeos no YouTube. Não é oferecida ao público.

Dados acessados

  • Dados públicos e estatísticas dos canais autorizados, obtidos pela YouTube Data API, YouTube Analytics API e YouTube Reporting API: lista de vídeos, títulos, visibilidade, visualizações, impressões, taxa de cliques, retenção e origem do tráfego.
  • O acesso usa somente permissões de leitura. A ferramenta não publica, não edita e não apaga nada.

Como os dados são usados e guardados

  • Os dados ficam guardados apenas no computador do dono, em um banco de dados local, e servem só para gerar relatórios de desempenho dos próprios canais.
  • Os dados não são vendidos, não são compartilhados com terceiros e não são usados para publicidade.
  • As credenciais de acesso ficam somente no computador do dono e nunca são publicadas.

Políticas do Google

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado, e os Termos de Serviço do YouTube. Veja também a Política de Privacidade do Google.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Ao revogar, os dados locais podem ser apagados pelo dono.
